## 学习目标

学完本模块后，你将能够：

1. 理解机器学习的三种学习范式及其适用场景
2. 掌握深度学习核心架构（CNN、RNN、Transformer）
3. 理解大语言模型的工作原理和应用方式
4. 了解计算机视觉和NLP的主要任务类型
5. 掌握召回率、精确率等核心评估指标及其业务含义
6. 能够与AI工程师进行有效的技术沟通
