# 机器学习基础概念

## 一、什么是机器学习

机器学习是人工智能的一个分支，它使计算机能够从数据中学习模式，而无需进行明确编程。

**核心思想**：通过算法从数据中自动学习规律，并用这些规律对新数据进行预测或决策。

## 二、三种学习范式

### 1. 监督学习（Supervised Learning）

**定义**：使用带有标签的数据进行训练，模型学习输入与输出之间的映射关系。

**典型任务**：
- **分类（Classification）**：预测离散标签
  - 二分类：垃圾邮件检测、情感分析
  - 多分类：图像识别、文本分类
- **回归（Regression）**：预测连续数值
  - 房价预测、销量预测、股价预测

**常用算法**：
- 线性回归（Linear Regression）
- 逻辑回归（Logistic Regression）
- 决策树（Decision Tree）
- 随机森林（Random Forest）
- 支持向量机（SVM）
- K近邻（KNN）

**产品应用场景**：
- 用户画像标签预测
- 风控模型（欺诈检测）
- 推荐系统（点击率预测）

---

### 2. 无监督学习（Unsupervised Learning）

**定义**：使用无标签的数据进行训练，模型自动发现数据中的模式和结构。

**典型任务**：
- **聚类（Clustering）**：将相似数据分组
  - K-Means：用户分群、商品分类
  - DBSCAN：密度聚类
- **降维（Dimensionality Reduction）**：减少数据维度
  - PCA：主成分分析
  - t-SNE：可视化高维数据

**常用算法**：
- K-Means
- DBSCAN
- PCA
- Autoencoder（自编码器）

**产品应用场景**：
- 用户分群（精细化运营）
- 异常检测（数据清洗）
- 特征提取（数据预处理）

---

### 3. 强化学习（Reinforcement Learning）

**定义**：智能体通过与环境交互，通过试错学习获得最大奖励的策略。

**核心要素**：
- **智能体（Agent）**：学习的主体
- **环境（Environment）**：智能体所处的场景
- **状态（State）**：环境的当前情况
- **动作（Action）**：智能体的行为
- **奖励（Reward）**：对动作的反馈

**常用算法**：
- Q-Learning
- Deep Q-Network（DQN）
- Policy Gradient（策略梯度）
- Actor-Critic

**产品应用场景**：
- 游戏AI（AlphaGo）
- 推荐系统（动态优化策略）
- 机器人控制
- 资源调度优化

---

## 三、机器学习流程

```
数据收集 → 数据清洗 → 特征工程 → 模型选择 → 模型训练 → 模型评估 → 模型部署 → 模型监控
```

### 关键环节说明

| 环节 | 说明 | 产品经理关注点 |
|------|------|----------------|
| 数据收集 | 获取训练所需数据 | 数据来源、数据质量、数据合规 |
| 数据清洗 | 处理缺失值、异常值 | 数据完整性、噪声处理 |
| 特征工程 | 提取和选择有用特征 | 特征定义、特征重要性 |
| 模型选择 | 选择合适的算法 | 算法复杂度、推理速度 |
| 模型训练 | 用数据训练模型 | 训练时间、算力需求 |
| 模型评估 | 评估模型性能 | 指标定义、效果验收 |
| 模型部署 | 上线到生产环境 | 部署方式、服务稳定性 |
| 模型监控 | 监控模型表现 | 漂移检测、效果追踪 |

## 四、模型评估指标

### 分类任务指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 准确率（Accuracy） | (TP+TN)/(TP+TN+FP+FN) | 总体预测正确率 |
| 精确率（Precision） | TP/(TP+FP) | 预测为正例的样本中实际为正例的比例 |
| 召回率（Recall） | TP/(TP+FN) | 实际为正例的样本中被预测为正例的比例 |
| F1分数（F1-Score） | 2×Precision×Recall/(Precision+Recall) | 精确率和召回率的调和平均 |
| AUC-ROC | - | 模型区分正负样本的能力 |

### 回归任务指标

| 指标 | 公式 | 说明 |
|------|------|------|
| MAE（平均绝对误差） | (1/n)×Σ\|y_i - ŷ_i\| | 预测值与真实值的平均绝对差异 |
| MSE（均方误差） | (1/n)×Σ(y_i - ŷ_i)² | 预测值与真实值的平均平方差异 |
| RMSE（均方根误差） | √[(1/n)×Σ(y_i - ŷ_i)²] | MSE的平方根，与原数据单位一致 |
| R²（决定系数） | 1 - (SS_res/SS_tot) | 模型解释数据变异的比例，越接近1越好 |

## 五、常见问题与坑点

### 1. 数据质量问题

**问题**：训练数据质量差（噪声、缺失值、标签错误）

**影响**：模型效果差，"垃圾输入，垃圾输出"

**对策**：
- 数据清洗流程标准化
- 数据标注质量把控
- 定期检查数据分布

### 2. 过拟合（Overfitting）

**问题**：模型在训练数据上表现很好，但在测试数据上表现差

**原因**：模型过于复杂，学习到了训练数据的噪声

**对策**：
- 增加训练数据量
- 使用正则化（L1、L2）
- 简化模型结构
- 交叉验证

### 3. 欠拟合（Underfitting）

**问题**：模型在训练数据和测试数据上表现都很差

**原因**：模型过于简单，无法捕捉数据的复杂模式

**对策**：
- 增加模型复杂度
- 特征工程（增加更多特征）
- 使用更强大的模型

### 4. 数据分布漂移（Data Drift）

**问题**：生产环境的数据分布与训练数据分布不一致

**影响**：模型效果随时间下降

**对策**：
- 定期监控数据分布
- 设置漂移告警
- 定期重新训练模型
