# 深度学习核心技术

## 一、什么是深度学习

深度学习是机器学习的一个子领域，使用多层神经网络来学习数据的高级特征表示。

**与传统机器学习的区别**：
- 传统机器学习依赖人工特征工程
- 深度学习自动从数据中学习特征

## 二、神经网络基础

### 1. 神经元（Neuron）

**模型**：模拟生物神经元的工作原理

```
输入 → 加权求和 → 激活函数 → 输出
```

**数学表达式**：
```
y = σ(w₁x₁ + w₂x₂ + ... + wₙxₙ + b)
```

其中：
- x₁, x₂, ..., xₙ：输入
- w₁, w₂, ..., wₙ：权重
- b：偏置
- σ：激活函数

### 2. 激活函数（Activation Function）

**作用**：引入非线性，使神经网络能够学习复杂模式

| 激活函数 | 特点 | 适用场景 |
|----------|------|----------|
| Sigmoid | 将输出压缩到(0,1) | 二分类输出层 |
| Tanh | 将输出压缩到(-1,1) | 隐藏层 |
| ReLU | 简单快速，梯度消失问题少 | 隐藏层（最常用） |
| Leaky ReLU | 解决ReLU的死亡神经元问题 | 隐藏层 |
| Softmax | 将输出转化为概率分布 | 多分类输出层 |

### 3. 神经网络结构

```
输入层 → 隐藏层1 → 隐藏层2 → ... → 隐藏层n → 输出层
```

- **输入层**：接收原始数据
- **隐藏层**：提取特征（可以有多层）
- **输出层**：产生最终预测结果

## 三、卷积神经网络（CNN）

### 1. 核心思想

利用图像的局部相关性，通过卷积操作提取空间特征。

### 2. 核心组件

| 组件 | 作用 |
|------|------|
| 卷积层（Convolutional Layer） | 提取局部特征（边缘、纹理） |
| 池化层（Pooling Layer） | 降维，减少参数数量 |
| 全连接层（Fully Connected Layer） | 整合特征，输出预测结果 |

### 3. 卷积操作

```
输入特征图 × 卷积核 → 输出特征图
```

**关键参数**：
- **卷积核大小**：如3×3、5×5
- **步长（Stride）**：卷积核移动的步长
- **填充（Padding）**：在输入边缘填充零，保持输出尺寸

### 4. 常用CNN架构

| 架构 | 特点 | 应用 |
|------|------|------|
| LeNet-5 | 早期CNN架构 | 手写数字识别 |
| AlexNet | 深度CNN里程碑 | 图像分类 |
| VGGNet | 统一使用3×3卷积 | 图像分类 |
| ResNet | 残差连接，解决梯度消失 | 图像分类、检测 |
| EfficientNet | 效率优化，参数量少 | 移动端应用 |

### 5. 产品应用场景

- 图像分类（图片搜索）
- 目标检测（自动驾驶、安防）
- 图像分割（医疗影像分析）
- 图像生成（AI绘画）

## 四、循环神经网络（RNN）

### 1. 核心思想

处理序列数据，通过循环连接保留历史信息。

### 2. RNN结构

```
h_t = σ(W_hh h_{t-1} + W_xh x_t + b_h)
y_t = σ(W_hy h_t + b_y)
```

其中：
- x_t：时刻t的输入
- h_t：时刻t的隐藏状态
- y_t：时刻t的输出

### 3. 问题与改进

#### 问题：梯度消失/爆炸

**原因**：长序列训练时，梯度在时间维度上传播时会消失或爆炸

#### 改进方案

| 方案 | 说明 |
|------|------|
| LSTM | 引入门机制（遗忘门、输入门、输出门），解决梯度消失 |
| GRU | 简化LSTM，合并遗忘门和输入门为更新门 |

### 4. LSTM结构

```
遗忘门：f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
输入门：i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
候选状态：C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
细胞状态：C_t = f_t × C_{t-1} + i_t × C̃_t
输出门：o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
隐藏状态：h_t = o_t × tanh(C_t)
```

### 5. 产品应用场景

- 文本生成（故事续写）
- 机器翻译
- 语音识别
- 时间序列预测

## 五、Transformer

### 1. 核心思想

基于自注意力机制（Self-Attention），并行处理序列数据。

### 2. 自注意力机制

**作用**：计算序列中每个位置与其他位置的相关性

**计算过程**：

```
Q = X × W_Q  (Query)
K = X × W_K  (Key)
V = X × W_V  (Value)

Attention(Q, K, V) = softmax(QKᵀ/√d_k) × V
```

**多头注意力（Multi-Head Attention）**：
- 并行计算多个注意力头
- 每个头学习不同的语义关系
- 最后拼接输出

### 3. Transformer架构

```
输入 → Embedding + Positional Encoding → 编码器层（N层）→ 解码器层（N层）→ 输出
```

#### 编码器（Encoder）

```
多头自注意力 → 残差连接 + LayerNorm → 前馈网络 → 残差连接 + LayerNorm
```

#### 解码器（Decoder）

```
多头自注意力（掩码） → 残差连接 + LayerNorm → 多头交叉注意力 → 残差连接 + LayerNorm → 前馈网络 → 残差连接 + LayerNorm
```

### 4. 位置编码（Positional Encoding）

**作用**：为序列中的每个位置添加位置信息

**公式**：
```
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

### 5. Transformer变体

| 变体 | 特点 |
|------|------|
| BERT | 双向Transformer，用于预训练 |
| GPT | 单向Transformer（仅解码器），自回归生成 |
| T5 | 统一框架，将所有NLP任务转化为文本生成 |
| RoBERTa | BERT改进版，更大批次训练 |

### 6. 产品应用场景

- 大语言模型（GPT、LLaMA）
- 机器翻译（Google Translate）
- 文本摘要
- 问答系统

## 六、深度学习训练技巧

### 1. 正则化

| 方法 | 说明 |
|------|------|
| Dropout | 随机丢弃部分神经元，防止过拟合 |
| L1/L2正则化 | 对权重添加惩罚项 |
| 数据增强 | 通过变换增加训练数据多样性 |

### 2. 优化器

| 优化器 | 特点 |
|--------|------|
| SGD | 基础优化器，学习率需手动调 |
| Adam | 自适应学习率，最常用 |
| RMSprop | 适合非平稳目标 |
| Adagrad | 适合稀疏数据 |

### 3. 学习率调度

| 策略 | 说明 |
|------|------|
| 恒定学习率 | 固定学习率 |
| 学习率衰减 | 随训练轮数降低学习率 |
| Warmup | 初始阶段使用小学习率，逐步增加 |
| Cosine Annealing | 余弦函数调整学习率 |

### 4. 批归一化（Batch Normalization）

**作用**：加速训练，稳定梯度

**原理**：对每个批次的输入进行标准化处理

## 七、产品经理关注点

### 1. 模型复杂度 vs 推理速度

| 模型 | 复杂度 | 推理速度 | 适用场景 |
|------|--------|----------|----------|
| CNN轻量模型 | 低 | 快 | 移动端、实时场景 |
| 大型Transformer | 高 | 慢 | 离线处理、高精度需求 |

### 2. 训练资源需求

- GPU算力：训练大型模型需要多GPU
- 训练时间：大型模型可能需要数天到数周
- 数据量：深度学习需要大量标注数据

### 3. 部署考量

- 模型大小：移动端需要轻量级模型
- 推理延迟：实时应用需要低延迟
- 内存占用：嵌入式设备内存有限
