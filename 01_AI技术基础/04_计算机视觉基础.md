# 计算机视觉基础

## 一、什么是计算机视觉

计算机视觉是人工智能的一个分支，旨在让计算机能够理解和处理图像与视频数据。

**核心目标**：从图像中提取有意义的信息，实现类似人类视觉的功能。

## 二、计算机视觉主要任务

### 1. 图像分类（Image Classification）

**定义**：判断图像属于哪个类别

**应用场景**：
- 照片分类（猫/狗/汽车）
- 内容审核（色情/暴力/正常）
- 产品识别（条形码/二维码）

**常用模型**：
- AlexNet
- ResNet
- EfficientNet
- ViT（Vision Transformer）

**评估指标**：Top-1准确率、Top-5准确率

---

### 2. 目标检测（Object Detection）

**定义**：识别图像中的物体并定位其位置

**核心输出**：
- 物体类别
- 边界框（Bounding Box）
- 置信度

**两阶段方法**：
- R-CNN → Fast R-CNN → Faster R-CNN
- Mask R-CNN（实例分割）

**单阶段方法**：
- YOLO（You Only Look Once）
- SSD（Single Shot MultiBox Detector）
- FCOS（Fully Convolutional One-Stage）

**应用场景**：
- 自动驾驶（行人/车辆检测）
- 安防监控（异常行为检测）
- 医疗影像（病灶检测）

---

### 3. 图像分割（Image Segmentation）

**定义**：将图像分割为不同区域，每个区域对应不同物体

**类型**：
- **语义分割**：每个像素分类（同类物体相同标签）
- **实例分割**：区分同一类的不同实例

**常用模型**：
- U-Net（医疗影像分割）
- DeepLab
- Mask R-CNN

**应用场景**：
- 医疗影像分析（器官分割）
- 自动驾驶（车道分割）
- 卫星图像分析（土地利用分类）

---

### 4. 图像生成（Image Generation）

**定义**：根据输入生成新的图像

**技术方法**：

#### 方法一：GAN（生成对抗网络）

```
生成器（Generator）：生成假图像
判别器（Discriminator）：判断图像真假
训练目标：生成器试图欺骗判别器，判别器试图区分真假
```

**经典模型**：
- DCGAN
- StyleGAN
- CycleGAN（图像风格转换）

#### 方法二：扩散模型（Diffusion Model）

**原理**：从噪声逐步去噪生成图像

**经典模型**：
- Stable Diffusion
- DALL-E
- Imagen

**应用场景**：
- AI绘画（Midjourney、Stable Diffusion）
- 图像修复（去除水印/瑕疵）
- 数据增强（生成训练样本）

---

### 5. 图像检索（Image Retrieval）

**定义**：根据查询图像找到相似图像

**技术流程**：
```
图像 → 特征提取（CNN） → 特征向量 → 相似度匹配
```

**常用方法**：
- 基于特征的检索
- 哈希检索
- 向量检索

**应用场景**：
- 商品搜索（拍照搜同款）
- 图像查重
- 人脸识别

---

### 6. 人脸识别（Face Recognition）

**定义**：识别图像中的人脸并匹配身份

**技术流程**：
```
人脸检测 → 人脸对齐 → 特征提取 → 特征比对
```

**常用模型**：
- FaceNet
- ArcFace
- InsightFace

**应用场景**：
- 门禁系统
- 身份认证
- 人脸支付

---

## 三、图像处理基础

### 1. 图像表示

**数字图像**：由像素组成的二维数组

**颜色空间**：
- RGB：红、绿、蓝三通道
- HSV：色相、饱和度、明度
- Grayscale：灰度图

**图像格式**：
- JPEG：有损压缩，适合照片
- PNG：无损压缩，支持透明
- BMP：无压缩，文件大

### 2. 图像预处理

**常用操作**：
- 缩放（Resize）
- 裁剪（Crop）
- 旋转（Rotate）
- 翻转（Flip）
- 归一化（Normalization）
- 数据增强（Data Augmentation）

### 3. 数据增强技术

| 技术 | 说明 |
|------|------|
| 随机裁剪 | 随机裁剪图像的一部分 |
| 随机翻转 | 水平或垂直翻转 |
| 颜色抖动 | 随机调整亮度、对比度、饱和度 |
| 高斯噪声 | 添加高斯噪声 |
| MixUp | 混合两张图像 |

## 四、计算机视觉产品架构

### 1. 典型架构

```
图像输入 → 预处理 → 模型推理 → 后处理 → 结果输出
```

### 2. 关键组件

| 组件 | 说明 |
|------|------|
| 图像采集 | 摄像头、上传、API |
| 预处理模块 | 缩放、归一化、数据增强 |
| 模型推理 | GPU/CPU推理引擎 |
| 后处理 | 边界框过滤、NMS（非极大值抑制） |
| 结果存储 | 数据库存储识别结果 |

### 3. 性能优化

| 优化方向 | 方法 |
|----------|------|
| 模型压缩 | 剪枝、量化、知识蒸馏 |
| 推理加速 | TensorRT、ONNX Runtime |
| 硬件加速 | GPU、TPU、NPU |

## 五、产品经理关注点

### 1. 数据需求

- **数据量**：训练需要大量标注图像
- **数据多样性**：覆盖不同场景、光照、角度
- **数据质量**：标注准确性

### 2. 性能指标

| 指标 | 说明 |
|------|------|
| 准确率 | 识别正确的比例 |
| 召回率 | 漏检率 |
| 推理延迟 | 从输入到输出的时间 |
| FPS | 每秒处理帧数 |

### 3. 部署考量

- **移动端部署**：模型大小、推理速度
- **边缘部署**：嵌入式设备算力有限
- **云端部署**：API调用成本

### 4. 常见挑战

- **光照变化**：不同光照条件下识别效果差异
- **视角变化**：多角度识别困难
- **遮挡问题**：物体部分遮挡
- **小目标检测**：小物体识别困难
