# A/B测试与实验设计

## 一、A/B测试概述

### 1. 什么是A/B测试

A/B测试是一种对比实验方法，将用户随机分为两组，每组使用不同的产品版本，通过统计分析判断哪个版本效果更好。

**核心思想**：通过控制变量，科学验证产品变更的效果。

### 2. A/B测试适用场景

| 场景类型 | 说明 | 示例 |
|----------|------|------|
| 功能优化 | 测试新功能效果 | 新推荐算法 vs 旧算法 |
| UI优化 | 测试界面变化 | 按钮颜色、文案调整 |
| 策略调整 | 测试策略变化 | 定价策略、推荐策略 |
| AI模型迭代 | 测试新模型效果 | 新模型 vs 旧模型 |

### 3. A/B测试流程

```
假设提出 → 实验设计 → 实验执行 → 数据收集 → 统计分析 → 结果决策
```

## 二、实验设计

### 1. 假设设计

**假设要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| 问题 | 要解决什么问题 | 推荐算法效果不佳 |
| 假设 | 变更能带来什么改善 | 新算法能提升10%点击率 |
| 指标 | 用什么指标衡量 | 用户点击率（CTR） |
| 显著性 | 需要达到什么统计显著性 | p<0.05 |

**假设模板**：
```
如果我们将[当前方案]改为[新方案]，那么[核心指标]将[预期变化]，置信度[X%]。
```

### 2. 分组设计

#### 对照组（Control Group）
- 使用当前方案
- 作为基准对比

#### 实验组（Treatment Group）
- 使用新方案
- 测试效果

#### 分组原则

| 原则 | 说明 |
|------|------|
| 随机分配 | 用户随机分组 |
| 样本量相等 | 两组样本量尽量相等 |
| 同期测试 | 同一时间段测试 |
| 隔离性 | 避免其他因素干扰 |

### 3. 样本量计算

**计算公式**：
```
样本量 = (Z² × (p₁(1-p₁) + p₂(1-p₂))) / (p₂ - p₁)²
```

| 参数 | 说明 | 常用值 |
|------|------|--------|
| Z | 置信水平对应的Z值 | 95%置信度Z=1.96 |
| p₁ | 对照组预期转化率 | 根据历史数据 |
| p₂ | 实验组预期转化率 | 预期提升后的值 |

**在线计算器**：
- Evan Miller's Sample Size Calculator
- Google Optimize

### 4. 实验周期

**确定原则**：

| 因素 | 说明 |
|------|------|
| 样本量需求 | 达到所需样本量的时间 |
| 用户行为周期 | 考虑周/月周期性 |
| 最小观察期 | 至少观察1个完整周期 |

**经验法则**：
- 短期实验：7-14天
- 中期实验：2-4周
- 长期实验：1个月以上

## 三、实验执行

### 1. 流量分配

| 分配方式 | 说明 | 适用场景 |
|----------|------|----------|
| 均匀分配 | 50% vs 50% | 标准A/B测试 |
| 小流量测试 | 1% vs 99% | 风险较高的变更 |
| 多臂测试 | 多组同时测试 | 多个方案对比 |

### 2. 数据收集

**收集内容**：

| 数据类型 | 说明 |
|----------|------|
| 核心指标 | 主要关注的指标 |
| 辅助指标 | 相关指标 |
| 用户行为数据 | 点击、转化、停留等 |
| 用户反馈 | 满意度、NPS等 |

**数据收集原则**：
- 全面收集
- 实时监控
- 数据完整

### 3. 实验监控

**监控内容**：

| 监控项 | 说明 |
|--------|------|
| 样本量 | 是否达到预期 |
| 指标变化 | 是否有异常波动 |
| 数据质量 | 是否有数据异常 |
| 用户反馈 | 是否有负面反馈 |

**中止条件**：

| 条件 | 说明 |
|------|------|
| 效果显著差 | 实验组效果显著低于对照组 |
| 数据异常 | 数据收集出现问题 |
| 业务紧急 | 需要紧急上线其他变更 |

## 四、统计分析

### 1. 统计检验方法

#### 卡方检验（Chi-squared Test）
- 适用场景：分类数据（点击率、转化率）
- 零假设：两组比例无差异

#### t检验（t-test）
- 适用场景：连续数据（停留时长、消费金额）
- 零假设：两组均值无差异

#### 置信区间（Confidence Interval）
- 提供效果估计的范围
- 常用95%置信区间

### 2. 统计显著性

**p值解读**：

| p值 | 解读 |
|-----|------|
| p < 0.05 | 差异显著，拒绝零假设 |
| p > 0.05 | 差异不显著，无法拒绝零假设 |

**注意**：
- p值不是效果大小的衡量
- 小样本可能导致假阳性或假阴性

### 3. 效果计算

**绝对提升**：
```
绝对提升 = 实验组指标 - 对照组指标
```

**相对提升**：
```
相对提升 = (实验组指标 - 对照组指标) / 对照组指标 × 100%
```

**置信区间**：
```
效果估计值 ± 边际误差
```

## 五、结果决策

### 1. 决策矩阵

| 情况 | 决策 |
|------|------|
| 效果显著且正向 | 全量上线 |
| 效果显著且负向 | 放弃该方案 |
| 效果不显著 | 扩大样本量或放弃 |
| 效果正向但不显著 | 继续观察或扩大样本量 |

### 2. 决策考虑因素

| 因素 | 说明 |
|------|------|
| 统计显著性 | 是否达到p<0.05 |
| 效果大小 | 提升是否有业务价值 |
| 样本量 | 是否足够 |
| 实验周期 | 是否覆盖完整周期 |
| 辅助指标 | 是否有负面影响 |

### 3. 结果沟通

**沟通要点**：

| 要点 | 说明 |
|------|------|
| 实验背景 | 为什么做这个实验 |
| 实验设计 | 如何设计的 |
| 实验结果 | 数据结果如何 |
| 统计分析 | 是否显著 |
| 业务建议 | 下一步怎么做 |

## 六、高级实验设计

### 1. 多变量测试（Multivariate Test）

**定义**：同时测试多个变量的组合效果

**适用场景**：
- 需要优化多个因素
- 因素之间可能有交互作用

**注意事项**：
- 样本量需求大
- 分析复杂度高

### 2. 序列测试（Sequential Testing）

**定义**：在实验过程中持续分析，达到显著性即停止

**优点**：
- 节省时间
- 减少样本浪费

**缺点**：
- 增加分析复杂度
- 需要专门工具

### 3. 互斥实验

**定义**：多个实验同时进行，但用户只参与一个实验

**适用场景**：
- 需要同时测试多个独立变更

**实现方式**：
- 用户分桶
- 每个桶只参与一个实验

## 七、常见问题与坑点

### 1. 样本量不足

**问题**：实验样本量不够，结果不可信

**对策**：
- 提前计算样本量
- 延长实验周期
- 使用统计功效分析

### 2. 数据污染

**问题**：数据受到其他因素干扰

**对策**：
- 确保分组隔离
- 控制其他变量
- 排除异常数据

### 3. 多重比较问题

**问题**：测试多个指标导致假阳性率增加

**对策**：
- 聚焦核心指标
- 使用Bonferroni校正
- 控制检验次数

### 4. 忽略辅助指标

**问题**：只关注核心指标，忽略负面影响

**对策**：
- 同时监控辅助指标
- 评估整体影响
- 综合决策
