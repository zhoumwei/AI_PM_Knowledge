## 每篇能力文档的统一结构

为便于学习，29 篇能力文档均采用一致框架：

1. **能力定义** — 这项能力是什么
2. **为什么重要** — 价值与不掌握的后果
3. **核心方法论/知识** — 系统、专业的主体内容
4. **实操方法/流程** — 可直接照做的步骤
5. **AI PM 差异化 / 关键实践** — 与传统 PM 的区别
6. **常见误区** — 高频踩坑与纠正
7. **实战案例/练习** — 多结合 AIOPS 项目
8. **自测题** — 检验掌握程度
9. **延伸阅读** — 链回知识库其他模块

## 自评方法

每项能力按 0-100 打分，维度取平均分。使用 [06_自评与提升计划模板.md](06_自评与提升计划模板.md) 每季度自评。

| 分数段 | 等级 | 说明 | 行动 |
|--------|------|------|------|
| 90-100 | S | 精通，能输出方法论 | 沉淀为团队规范 |
| 75-89 | A | 熟练，能独立完成 | 分享给他人 |
| 60-74 | B | 掌握，能指导下完成 | 刻意练习 |
| 40-59 | C | 了解，需要帮助 | 系统性学习 |
| 0-39 | D | 不了解 | 从入门开始 |

## 推荐学习路径

1. **快速补齐短板**：先用自评模板打分，优先学分数最低的维度（多数人是商业化 58 / 技术协作 64）。
2. **新手系统路径**：01 基础产品 → 02 AI 专项 → 03 技术协作 → 04 商业化 → 05 职业发展。
3. **结合实战**：以 [AIOPS_Troubleshooting_PRD](../AIOPS_Troubleshooting_PRD/) 真实项目为载体练习。
4. **季度循环**：自评 → 选 2-3 项短板制定计划 → 项目中练习 → 复盘 → 再自评。
