# 留存转化

> 所属维度：商业化能力 ｜ 参考分：60

## 一、能力定义

留存转化能力包含两件事：**让用户持续回来用（留存）**，以及**把免费/试用用户转化为付费用户（转化）**。拉新决定增长速度，留存与转化决定增长质量与收入。

> 获取一个新用户的成本通常是留住老用户的 5 倍以上。AI 产品还面临"新鲜感退潮即流失"的特殊挑战。

## 二、留存（Retention）

### 2.1 留存率定义
- 次日/7 日/30 日留存率：某日新增用户在第 N 天仍活跃的比例
- 用 **Cohort（同期群）** 分析：按注册批次分组看留存曲线，避免平均数误导

### 2.2 留存曲线的三种形态
- 持续下滑至零：产品没找到持续价值（危险）
- 下滑后平稳：找到核心用户群（健康，需提升平稳高度）
- 微笑曲线：早期下滑后回升（网络效应/习惯养成）

### 2.3 AI 产品的留存抓手
| 机制 | 做法 |
|------|------|
| 习惯回路 | 固定高频场景嵌入工作流（如每天排障都用）|
| 价值累积 | 越用越懂你（记忆、历史、个性化知识库）|
| 数据资产 | 用户沉淀的对话、知识库、配置形成迁移成本 |
| 效果稳定 | 输出质量稳定可靠，减少"时好时坏"的不信任 |
| 主动触达 | 结果通知、定期报告、智能提醒（适度，防打扰）|

### 2.4 流失诊断
- 定位流失高发节点（漏斗 + Cohort）
- 定性回访流失用户，区分：没体验到价值 / 效果不稳定 / 有替代品 / 价格 / 场景低频
- 建立流失预警信号（使用频次骤降、额度长期不用）

## 三、转化（Conversion）

### 3.1 付费转化漏斗
```
免费注册 → 体验到价值（激活）→ 撞到付费墙（额度/高级功能）
   → 理解付费价值 → 信任 → 下单支付 → 续费/扩展
```

### 3.2 付费墙（Paywall）设计
- **硬墙**：不用就不能继续（强转化、易反感）
- **软墙**：功能可用但有限制（次数、额度、高级模型、去水印）
- 时机：在用户**刚体验到价值、且产生更强需求**时出现（如连续多次获得满意结果、额度将尽）
- 信息：清楚传达付费能得到什么、与免费的差异

### 3.3 AI 产品特有的转化杠杆
| 杠杆 | 说明 |
|------|------|
| 效果可感知 | 用"对比报告/数据"让用户明确感到 AI 带来的价值与节省 |
| 额度焦虑 | 用量接近上限时温和提醒，展示加量后的收益 |
| 高级能力 | 更强模型、更大上下文、更高并发、RAG/Agent 能力作为付费点 |
| 信任累积 | 稳定准确的输出积累信任，用户才愿为关键场景付费 |
| 协作/团队版 | 团队知识库、共享、管理能力驱动组织级付费 |

### 3.4 转化优化方法
- A/B 测试付费墙位置、文案、套餐、默认选项
- 优化支付流程（减少步骤、支持常用支付、明确可取消）
- 对"高意图未付费"用户做定向召回（优惠、案例、答疑）
- 免费试用（Freemium / Free Trial）：给足体验价值的时间窗口

## 四、续费与扩展（B 端尤其重要）

- **续费率 / NRR（净收入留存率）**：SaaS 健康核心指标，NRR > 100% 说明老客户在增购
- **Land and Expand**：先小范围落地（一个团队），用价值驱动扩展到更多席位/部门
- 客户成功（CS）：主动帮助客户用出价值，而非等续费才联系
- 用量增长是 B 端增购信号（用量接近套餐上限时触发升级）

## 五、关键指标

| 指标 | 含义 |
|------|------|
| 次日/7日/30日留存 | 短期黏性 |
| 留存曲线平台高度 | 长期留存的核心 |
| DAU/MAU | 活跃与使用频次 |
| 付费转化率 | 免费→付费比例 |
| ARPU / ARR | 用户平均收入 / 年度经常性收入 |
| 流失率（Churn） | 用户/收入流失 |
| NRR | 净收入留存率（B 端） |
| 获客回本周期 | CAC 多久收回 |

## 六、常见误区

| 误区 | 纠正 |
|------|------|
| 只拉新不留存 | 漏水的池子，先补留存 |
| 付费墙过早 | 用户未体验价值就拦截，适得其反 |
| 用整体平均留存 | 用 Cohort 分批次看 |
| AI 靠新鲜感，不做习惯设计 | 嵌入高频工作流、积累数据资产 |
| 用户感受不到 AI 价值 | 用对比/数据显性化效果 |
| 只看签约不看续费 | SaaS 真正赚钱在续费与增购 |
| 忽视流失用户访谈 | 流失反馈是最有价值的改进输入 |

## 七、实战练习

为 AI 排障助手设计留存与转化方案：
1. 找到嵌入工作流的高频场景（每次告警/值班都用）
2. 设计让效果可感知的功能（归因准确率/节省时间报告）
3. 设计数据资产（历史案例库、团队 SOP）形成迁移成本
4. 确定免费额度与付费墙触发时机
5. 定义需要监控的留存与转化指标及目标值

## 八、自测题

1. 你的 7 日/30 日留存是多少？留存曲线在第几天趋平？
2. 用户流失的 Top 3 原因是什么？你怎么验证的？
3. 付费墙应该在用户旅程的什么时机出现？为什么？
4. B 端客户的 NRR 是多少？增购主要来自什么？
5. 你如何让用户"明确感知"到 AI 带来的价值？
