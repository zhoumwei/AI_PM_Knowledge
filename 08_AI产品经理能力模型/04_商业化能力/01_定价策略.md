# 定价策略

> 所属维度：商业化能力 ｜ 参考分：56

## 一、能力定义

定价策略是为产品设计**收费方式、价格水平与价格结构**，使收入既能覆盖成本（尤其 AI 推理成本）、又能匹配用户感知价值，还能支撑增长目标。

定价不是简单的"成本加个利润"，而是商业战略的直接体现。

## 二、定价的三种基本方法

| 方法 | 逻辑 | 适用 | 风险 |
|------|------|------|------|
| 成本加成 | 成本 ×（1+ 毛利率） | 成本稳定、竞争弱 | 忽视用户愿付价值 |
| 竞品对标 | 参考竞品定价 | 成熟市场 | 易陷价格战 |
| 价值定价 | 按用户获得的价值定价 | 价值可量化、差异化强 | 价值难衡量 |

**AI 产品建议以价值定价为主、成本为底线**：AI 带来的效率提升（省人力、省时间）往往远高于 token 成本，按价值定价才有利润空间。

## 三、AI 产品的主流收费模式

| 模式 | 说明 | 优点 | 风险/注意 |
|------|------|------|-----------|
| 订阅制（Subscription） | 按月/年付固定费用，含一定额度 | 收入可预测、用户决策简单 | 重度用户成本失控 |
| 按量计费（Usage-based） | 按 token/调用量/次数付费 | 成本与收入匹配、公平 | 收入波动、用户难预算 |
| 混合模式（Base + Usage） | 订阅底费 + 超量按量 | 兼顾稳定与成本 | 当前 AI 产品主流 |
| 按席位（Per Seat） | 按使用人数 | B 端传统、易理解 | 不反映真实 AI 用量 |
| 按结果/价值（Outcome-based） | 按解决的问题/节省成本分成 | 价值对齐、天花板高 | 效果难归因、交付重 |
| 一次性买断 | 一次付费永久使用 | 简单 | 不适合持续成本的 AI |
| 免费增值（Freemium） | 免费引流 + 付费升级 | 降低门槛、获客 | 免费额度被滥用 |

## 四、必须算清的单位经济学

| 指标 | 含义 | 健康参考 |
|------|------|----------|
| ARPU | 每用户平均收入 | - |
| COGS（单客成本） | 服务一个用户的成本，AI 主要是推理/token + 云 | - |
| 毛利率 | (收入−COGS)/收入 | SaaS 常追求 70%+；AI 产品要重点盯 |
| CAC | 获客成本 | - |
| LTV | 用户生命周期总价值 | - |
| LTV/CAC | 获客效率 | 通常 ≥ 3 |
| 回本周期 | CAC ÷ 单客月毛利 | 通常 < 12 个月 |

**AI 产品的生死线**：单个重度用户的推理成本不能高于其支付的费用。订阅制必须设置**用量上限/公平使用策略**，否则一个"刷量用户"就可能吃掉十个用户的利润。

## 五、定价设计步骤

```
明确目标（占市场 or 赚利润）→ 核算成本底线 → 评估用户感知价值
  → 选择收费模式 → 设计分层（免费/标准/企业）→ 小范围价格测试
  → 确定折扣/年付策略 → 监控毛利与用量 → 动态调整
```

### 分层设计要点（Good-Better-Best）
| 层级 | 面向 | 设计 |
|------|------|------|
| 免费版 | 引流/体验 | 限量（次数/token）、有水印或功能限制，目的是转化 |
| 专业版 | 个人/小团队 | 主力走量，含足够额度，超量按量 |
| 企业版 | 大客户 | 私有化、SSO、更高额度/并发、专属支持、定制合同 |

- 免费额度的设计：足够让用户体验到 **aha moment**，但不支撑重度使用
- 锚定效应：先展示高价企业版，衬托专业版划算
- 年付折扣：年付通常打 7-8 折，换取现金流和留存

## 六、价格测试与验证

- A/B 测试不同价格/付费墙位置（注意样本与伦理）
- 访谈探测支付意愿（Van Westendorp 价格敏感度法）
- 观察转化率、客单价、退款率、重度用户成本占比
- B 端常需销售验证客户预算区间

## 七、AI 定价的特殊陷阱

| 陷阱 | 应对 |
|------|------|
| 模型成本随用量上涨，订阅费固定 | 额度上限 + 超量按量（混合模式） |
| 模型涨价/降价传导 | 合同约定调价机制；多供应商 |
| 重度用户毛利为负 | 监控单客毛利，必要时限流/升档 |
| 免费用户白嫖 | 注册门槛、限额、水印、转化引导 |
| 输入输出成本差异大 | 按 token 类型计费或限制输出长度 |
| 私有化交付成本高 | 企业版单独定价，覆盖部署运维 |

## 八、常见误区

| 误区 | 纠正 |
|------|------|
| 拍脑袋定价 | 基于成本底线 + 价值 + 竞品 |
| 只定一次价 | 定期复盘毛利与用量，动态调整 |
| 免费额度无限制 | 必须设计公平使用与转化 |
| 只看收入不看单客毛利 | 重度用户可能越用越亏 |
| B 端照搬 C 端订阅 | B 端多用席位+额度+定制合同 |

## 九、实战练习

给定一个 AI 排障助手：单次归因平均消耗输入 3000 + 输出 800 token，模型综合单价约 ¥X/千 token，预计重度用户日均 20 次。
请计算：
1. 单用户日/月推理成本
2. 若订阅价 ¥Y/月，重度用户毛利是否为正？
3. 免费版每日应给多少次额度，既能体验 aha moment 又不被薅？
4. 设计专业版/企业版的分层与超量计费规则。

## 十、自测题

1. 你的产品当前采用什么收费模式？为什么适合？
2. 你的 LTV/CAC 和毛利率大概是多少？
3. 订阅制下如何防止重度用户吃掉利润？
4. 如果模型厂商涨价 20%，你的定价策略如何应对？
