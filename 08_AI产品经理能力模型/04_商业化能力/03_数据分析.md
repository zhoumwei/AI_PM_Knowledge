# 数据分析

> 所属维度：商业化能力 ｜ 参考分：60

## 一、能力定义

数据分析能力指 PM 能**建立指标体系、取数分析、用数据验证假设、驱动产品决策**。核心不是会多少统计公式，而是养成"用数据说话、让数据推翻直觉"的习惯。

## 二、数据分析解决的三类问题

| 类型 | 问题 | 方法 |
|------|------|------|
| 描述性 | 发生了什么 | 指标看板、趋势、分布 |
| 诊断性 | 为什么发生 | 下钻、维度拆解、漏斗、归因 |
| 实验性 | 改动有没有用 | A/B 测试、因果推断 |

（预测性/规范性通常由算法团队承担，PM 需能理解结论）

## 三、指标体系搭建

### 3.1 指标分层
```
北极星指标（战略层，1 个）
   └── 一级指标（业务结果，如收入、留存）
        └── 二级指标（过程，如各漏斗转化率）
             └── 监控指标（系统/质量，如延迟、错误率）
```

### 3.2 好指标的原则（OSM + SMART）
- 可衡量、可行动、有明确口径和统计周期
- 区分**领先指标**（预示未来，如激活率）与**滞后指标**（已发生，如月收入）
- 警惕虚荣指标（只涨不代表业务健康，如总注册数）

### 3.3 AI 产品的双层指标
| 层 | 指标 |
|----|------|
| 模型效果层 | 准确率、召回率、幻觉率、满意度、响应延迟、token 成本 |
| 业务价值层 | 激活、留存、使用频次、付费转化、效率提升（如 MTTR） |

**关键动作**：建立效果层与业务层的关联——证明"模型变好"确实带来"业务变好"（如归因准确率提升 → MTTR 下降 → 续费率提升）。

## 四、核心分析方法

### 4.1 漏斗分析
追踪用户在关键路径每一步的转化，定位最大流失点。
例：进入 → 发起首次 AI 对话 → 得到满意结果 → 次日回访 → 付费。

### 4.2 留存与 Cohort（同期群）分析
按用户"首次使用时间"分组，追踪各组随时间的留存曲线，避免用整体平均数掩盖真相。

### 4.3 维度下钻
对异常指标按维度拆解找原因：渠道、地区、端、用户分层、模型版本、Prompt 版本。
例：整体满意度下降 → 下钻发现是某模型版本在某类问题上变差。

### 4.4 趋势与对比
- 环比/同比
- 对照组思维（没有 A/B 时，找可对比的基准群体）

### 4.5 相关性 ≠ 因果性
两个指标一起变动不代表因果。验证因果靠 A/B 测试或更严谨方法（DID、PSM），尤其在评估 AI 功能价值时不能想当然。

## 五、数据驱动决策的流程

```
提出业务问题 → 转化为可分析假设 → 明确指标与口径
  → 取数（SQL/BI）→ 分析与可视化 → 得出结论与建议
  → 推动行动 → 回收结果验证
```

好的分析报告结构：**结论先行 → 关键数据支撑 → 原因分析 → 行动建议**。

## 六、PM 必备数据技能

| 技能 | 程度 |
|------|------|
| SQL | 会多表 join、聚合、窗口函数，能自助取数 |
| Excel/表格 | 透视表、常用函数 |
| BI 工具 | 会用 Tableau/Power BI/内部看板做图 |
| 埋点设计 | 能定义事件、属性、用户属性 |
| 统计常识 | 均值/中位数、分布、显著性、样本量、辛普森悖论 |

## 七、埋点基础

- 事件（Event）：用户做了什么（如 `ai_response_feedback`）
- 属性：事件的细节（如 `feedback=down`, `reason=hallucination`）
- 用户属性：分群依据（版本、套餐、角色）
- 原则：分析需求先行，反推要埋哪些点；关键路径全覆盖；上线前校验

## 八、常见误区

| 误区 | 纠正 |
|------|------|
| 只报数字不给结论与建议 | 分析要落到行动 |
| 把相关当因果 | 用实验验证 |
| 只看均值 | 看分布、分层、长尾 |
| 口径不统一 | 每个指标有唯一定义文档 |
| 用虚荣指标自我安慰 | 盯能代表价值的指标 |
| 数据不足也硬下结论 | 标注不确定性，补数据 |
| 辛普森悖论（整体与分组结论相反） | 务必分层看 |

## 九、实战练习（AI 排障）
问题："上线 AI 归因后，MTTR 是否真的下降？"
分析思路：
1. 明确 MTTR 口径与时间窗
2. 设对照组（未使用 AI 的故障）vs 实验组（使用 AI），或对比上线前后（注意混杂因素）
3. 分层：按故障级别、业务线、值班人群
4. 关联：归因准确率高的故障，MTTR 降幅是否更大
5. 输出结论 + 是否扩大灰度的建议

## 十、自测题

1. 你负责产品的北极星指标和 3 个关键二级指标是什么？口径是什么？
2. 最近一次"数据推翻你直觉"的决策是什么？
3. 模型效果指标与业务指标之间，你验证过因果关联吗？
4. 写一个你常用的多表 join + 聚合 SQL。
5. 整体转化率上升但某核心渠道在跌，你如何发现这类问题？
