## 核心经营公式

```
收入 = 付费用户数 × ARPU
利润 = 收入 −（获客成本 CAC + 服务成本 COGS + 运营成本）
健康度 = LTV / CAC（通常要求 > 3）
```

AI 产品相比传统软件，多了一块巨大且波动的**模型推理成本（COGS）**，这是商业化设计的关键变量，也是本维度的主线。

## 学习建议

1. 先建立单位经济学意识（单个用户/单次调用赚不赚钱）。
2. [04_成本控制](04_成本控制.md) 是 AI 产品最特有的商业化能力，重点掌握。
3. 用数据分析把增长、留存、定价串成闭环。
