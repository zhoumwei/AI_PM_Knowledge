# 简历优化

> 所属维度：职业发展能力 ｜ 参考分：66

## 一、能力定义

简历优化是把你的经历**精准、有说服力地呈现**，通过 HR 的关键词筛选和初筛、拿到面试机会。简历的唯一目的是"获得面试"，不是"记录全部人生"。

## 二、简历筛选的真相

- HR/招聘方初筛一份简历平均只有 **10-30 秒**
- 越来越多公司用 **ATS（简历筛选系统）**按关键词初筛
- AI PM 岗位通常要同时过 HR（看匹配度）和业务（看专业深度）两关

因此简历必须：**关键词到位、成果量化、重点前置、一目了然**。

## 三、AI PM 必备关键词

根据目标岗位 JD 自然嵌入（不要堆砌）：

| 类别 | 关键词 |
|------|--------|
| 通用 AI | 大模型、LLM、AIGC、生成式 AI |
| 核心技能 | RAG、Agent、Prompt Engineering、Function Calling |
| 模型/数据 | Embedding、向量数据库、微调（SFT/LoRA）、模型评估 |
| 工程 | MLOps、LangChain、知识库、多模态 |
| 产品 | 0-1、需求、PRD、数据驱动、A/B 测试、留存/转化 |

## 四、简历核心结构

1. **个人信息 + 一句话定位**：姓名、联系方式、求职意向；一句话概括你的差异化标签
2. **核心优势（Summary）**：3-4 条最强卖点（年限 + 领域 + 代表成果）
3. **工作经历**：倒序，公司/职位/时间，下面是**成果导向的 bullet**
4. **项目经历**：重点（尤其 AI 项目），STAR 精简版
5. **教育/证书/技能**：学历、相关技能、语言
6. **作品集/链接**：作品集、博客、GitHub（有则放，加分）

## 五、经历描述：动词 + 做法 + 量化结果（关键）

反例（职责罗列）：
> 负责 AI 产品的需求分析和原型设计，跟进开发上线。

正例（成果导向）：
> 主导智能排障 Agent 从 0 到 1，设计 RAG + 多 Agent 方案与三维评估体系，将根因 Top-3 召回率从 52% 提升至 83%，MTTR 降低 50%，月均推理成本下降 43%。

公式：**强动词 + 你做了什么（含 AI 方法）+ 带来的可量化结果**。

### 常用强动词
主导、设计、搭建、从 0 到 1、推动、优化、提升、降低、建立、落地。

### 量化方向（没有精确数据也要估算/用相对值）
- 效果：准确率/召回率提升百分点
- 效率：时长、人效、MTTR 变化
- 成本：token/人力/成本下降比例
- 增长：留存、转化、收入、用户量
- 规模：数据量、用户量、覆盖团队

## 六、AI 项目经历怎么写最出彩

突出"你懂行"的细节（与作品集呼应，但简历更精简）：
- 为什么做技术选型（RAG vs 微调、模型 A vs B）
- 你设计的关键机制（SOP 约束、人机协同边界、评估体系）
- 可量化的效果/成本/业务结果
- 体现端到端负责（从需求到上线到数据验证）

## 七、针对性优化

- **一岗一版**：针对 JD 调整 Summary、关键词、项目排序
- JD 里反复出现的词，简历里要有对应体现
- 不同方向（C 端 AI 应用 / B 端 AI 平台 / Agent 基建）突出不同经历
- 转行者：用"可迁移能力 + AI 相关实践/作品"补足，哪怕是个人项目/Demo

## 八、格式与细节

- 一页纸（经验极丰富可两页），PDF 格式防错乱
- 排版清爽、留白合理、字级有层次，便于 10 秒扫读
- 时间连续、无明显 unexplained 空档（或准备好说法）
- 检查错别字、公司/数据真实性
- 文件命名规范：姓名-AI产品经理-X年经验

## 九、常见误区

| 误区 | 纠正 |
|------|------|
| 大段岗位职责 | 改成成果导向 bullet |
| 没有数字 | 尽量全部量化 |
| 关键词缺失被 ATS 刷 | 对照 JD 嵌入专业词 |
| 一份海投 | 针对性调整 |
| AI 经历只写"接入大模型" | 写清方案、机制、效果 |
| 堆砌术语无细节 | 经得起业务面深挖 |
| 排版花哨难读 | 简洁清晰优先 |
| 信息造假 | 面试深挖必穿帮，绝不造假 |

## 十、自查清单

- [ ] 10 秒内能否看到最强的 3 个卖点？
- [ ] 是否覆盖目标 JD 的核心关键词？
- [ ] 每条经历是否都有量化结果？
- [ ] AI 项目是否体现了技术理解（而非套壳）？
- [ ] 是否有作品集链接？
- [ ] 是否针对该岗位调整过？
- [ ] PDF 格式、无错别字、排版清晰？
- [ ] 请同行/猎头帮忙看过？

## 十一、自测题

1. 不看资料，用一句话说出你的求职定位。
2. 把一条"职责式"经历改写成"动词+做法+量化结果"。
3. 目标 JD 中有哪些关键词是你简历目前缺失的？
4. 你最强的 3 个量化成果是什么？
