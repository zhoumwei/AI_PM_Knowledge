# 05 职业发展能力（参考分 68）

> 超越具体产品和技术的**长期竞争力**。前四个维度决定你"现在值多少钱"，职业发展能力决定你"3-5 年后能到什么位置"。

## 内在逻辑

```
项目复盘（输入端：把经历变经验）
   ↓
作品集 + 简历（沉淀端：把经验变成果展示）
   ↓
面试表达（输出端：把成果讲成 offer）
   ↓
职业规划（方向端：决定下一段路往哪走）
```

这五项形成一个持续运转的成长闭环，而不是只在找工作时才临时准备。

## 学习建议

1. **平时积累，而非临时抱佛脚**：每做完一个项目就复盘、更新作品集与简历。
2. **量化 AI PM 的差异化价值**：AI 相关成果务必带数据（准确率提升、成本下降、MTTR 缩短）。
3. **方向比努力重要**：定期（每半年）用 [职业规划](05_职业规划.md) 的方法校准方向。
