# 职业规划

> 所属维度：职业发展能力 ｜ 参考分：68

## 一、能力定义

职业规划是在理解行业趋势、认清自身禀赋的基础上，**有方向感地设定长期目标并拆解为阶段性行动**的能力。它回答的不是"我下一步学什么"，而是"我想成为什么样的人、走哪条路"。

## 二、为什么职业规划最重要也最容易被忽视

- 日常执行容易陷入"用战术勤奋掩盖战略懒惰"
- AI 行业变化极快，方向选择的影响被放大：同样努力，踩中赛道与错过赛道差距巨大
- 规划不是一次定终身，而是在变化中持续校准的罗盘

## 三、看清外部趋势：AI PM 的行业位置

- **需求侧**：企业从"尝鲜大模型"进入"要业务结果"的阶段，真正懂"AI + 业务落地 + 商业化"的 PM 稀缺
- **能力侧**：纯套壳产品门槛低、易被替代；有领域 know-how、懂 Agent/RAG、能为业务结果负责的 PM 更有壁垒
- **趋势侧**：Agent 化、多模态、私有化、垂直行业深耕是明确方向（如 AIOps、医疗、金融、法律）
- **风险侧**：部分初级、重复性 PM 工作会被 AI 工具提效压缩，需要向更高价值环节迁移

## 四、AI PM 的几条典型路径

| 路径 | 核心要求 | 适合人群 | 发展方向 |
|------|----------|----------|----------|
| 产品专家（垂直深耕） | 行业 know-how + AI 深度结合 | 喜欢钻研业务与场景 | 领域首席产品、行业解决方案专家 |
| 技术型 PM（MLOps/Agent 方向） | 强工程理解、技术判断力 | 有技术背景/愿深钻技术 | AI 平台产品、Agent 基建负责人 |
| AI 创业/业务负责人 | 产品+技术+商业综合能力 | 风险承受高、自驱 | 创始人、业务线 GM |
| 产品管理（People Manager） | 拿结果、搭团队、定战略 | 擅长带人协调 | 产品总监、VP of Product |
| AI 解决方案/售前 | 懂产品懂客户、表达强 | 擅长客户沟通 | 解决方案架构、商业化 |

这些路径不是非此即彼，中期可以组合（如"垂直行业 + 技术深度"）。

## 五、认清内部：自我盘点

定期（建议每半年）做一次自我盘点：

| 维度 | 问自己 |
|------|--------|
| 优势 | 我做得比多数人好的是什么？（可结合五大能力模型自评） |
| 短板 | 哪类工作我总做不好或很抗拒？ |
| 兴趣 | 做什么事我会进入心流、不觉得累？ |
| 价值观 | 我更看重收入、稳定、影响力、创造还是成长？ |
| 资源 | 我有哪些行业/人脉/技术/数据积累？ |
| 现实约束 | 城市、家庭、风险承受能力如何？ |

用本模块的[自评模板](../06_自评与提升计划模板.md)量化能力现状，定位差距。

## 六、目标设定与拆解

### 6.1 用不同时间尺度
- **长期（3-5 年）**：我希望成为什么角色、具备什么标签？（方向性，可模糊）
- **中期（1 年）**：为支撑长期目标，今年要进入什么平台/主导什么项目/补齐什么能力？
- **短期（季度）**：具体的项目、技能、成果目标（要可执行、可检验）

### 6.2 目标要可检验
避免"我要变强"，改为：
- "1 年内主导一个 Agent 产品从 0 到 1 上线，Top-3 召回率做到 85%+，并沉淀成作品集"
- "本季度补齐商业化短板：算清单位经济、完成一次定价 A/B 测试"

### 6.3 用项目承载成长
能力最好在真实项目中长出来。主动争取能补齐短板、靠近目标的项目（如想深耕 Agent，就争取进入 Agent 相关项目）。

## 七、成长杠杆：如何进步更快

1. **选对平台与赛道**：好的项目、数据、团队比个人苦学更重要
2. **找到标杆与导师**：找到 1-2 位你想成为的人，分析差距、定期交流
3. **刻意练习**：在短板上设置有反馈的练习（做完就复盘、就被评审）
4. **输出倒逼输入**：写文章、做分享、建知识库（如本知识库），教是最好的学
5. **建立人脉与信息源**：高质量社群、行业会议、前沿论文/产品动态
6. **保持技术手感**：亲手用 Dify/LangChain 做 Demo，不与技术脱节

## 八、应对变化与不确定性

- **T 型 / π 型能力**：在 1-2 个领域有深度（竖），同时有产品/商业的广度（横），抗风险更强
- **拥抱工具**：把 AI 当能力放大器，主动用它提效，而非担心被替代
- **积累不易被替代的资产**：行业认知、复杂决策经验、信任关系、个人品牌
- **定期复盘方向**：行业剧变时，计划要能调整，但长期锚点（想成为谁）相对稳定

## 九、常见误区

| 误区 | 纠正 |
|------|------|
| 只规划下一份工作，不想要成为谁 | 从长期身份倒推中期选择 |
| 盲目追热点频繁换方向 | 在有积累的领域与趋势之间找交集 |
| 只列学习清单，不承接项目 | 用真实项目承载能力成长 |
| 目标全是"变强" | 拆成可检验的阶段性目标 |
| 忽视软实力与人脉 | 高级阶段影响力/协作极关键 |
| 一次规划再不复盘 | 每半年校准一次 |

## 十、行动练习

1. 写下你的 3 年目标：希望具备的 3 个标签 / 想成为的角色。
2. 做一次五大能力自评，找出与目标差距最大的 2 项。
3. 确定 1 年内要主导/参与的关键项目。
4. 找 1 位行业标杆，列出你和他的 3 个关键差距。
5. 制定本季度 3 个可检验目标，并安排进日历。

## 十一、自测题

1. 你认为最厉害的 AI PM 是谁？你和他的核心差距在哪？
2. 你的 T 型/π 型能力中，"竖"（深度）是什么？
3. 如果 AI 继续演进，你现在工作中哪些部分可能被替代？你如何向高价值环节迁移？
4. 未来 3 年你想拥有的 3 个职业标签是什么？
5. 过去半年，你在哪件事上获得了最快的成长？为什么？
