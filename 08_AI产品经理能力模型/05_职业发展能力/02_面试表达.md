# 面试表达

> 所属维度：职业发展能力 ｜ 参考分：70

## 一、能力定义

面试表达是在有限时间内，**结构化、有说服力地呈现自己的经历、思考与匹配度**，并通过高质量反问判断岗位与公司的能力。

会做和会讲是两种能力。再好的经历，讲不出来也拿不到 offer。

## 二、面试的底层逻辑

面试官在有限时间内判断三件事：
1. **你能不能做**（能力/经验是否匹配）
2. **你愿不愿意做**（动机/稳定性）
3. **和你合作爽不爽**（沟通、文化匹配）

AI PM 面试还要额外验证：你是"真懂 AI"还是"追热点套概念"。

## 三、核心表达框架

### 3.1 STAR 法则（讲项目）
Situation（背景）→ Task（任务）→ Action（行动，重点）→ Result（量化结果）。
- 时间分配：Action 占 60% 以上
- AI 项目重点讲：选型决策、评估方法、效果与成本权衡（详见[作品集](01_作品集.md)）

### 3.2 电梯演讲（自我介绍）
30 秒版本，结构：我是谁 + 核心定位 + 最亮眼的 1-2 个成果 + 为什么匹配这个岗位。
示例："我是一名专注企业级 AI Agent 的产品经理，曾主导智能排障产品从 0 到 1，将归因 Top-3 召回率从 52% 提升到 83%、MTTR 降低 50%。"

### 3.3 金字塔原理（答复杂问题）
先给结论，再给 2-3 个支撑论据，最后可展开细节。避免铺垫半天没有观点。

## 四、AI PM 高频问题与准备思路

### 4.1 专业能力类
| 问题 | 回答要点 |
|------|----------|
| 怎么评估一个 AI 产品/模型的效果？ | 离线+在线、指标体系、评测集、过程评估（不只最终答案） |
| RAG 效果不好怎么优化？ | 分块、embedding、混合检索、rerank、查询改写、知识库质量，且讲如何定位是检索还是生成问题 |
| 如何做模型选型？ | 自己数据集上评测 + 成本/延迟/合规/生态，举真实案例 |
| Prompt 调优的思路？ | 结构化、SOP、few-shot、版本管理与回归评测 |
| Agent 如何保证安全可控？ | 自动化层级、HITL、置信度阈值、工具权限、兜底 |
| 如何控制 AI 成本？ | 模型路由、缓存、上下文压缩、配额，讲量化效果 |
| 效果达标但用户不用怎么办？ | 从价值感知、工作流嵌入、体验、信任角度分析 |

### 4.2 项目深挖类
- "这个指标具体怎么定义/怎么测的？"
- "如果重来你会怎么做？"
- "你和算法/研发有分歧时怎么解决的？"
- "项目最难的点是什么？"
（提前对每个项目准备 5 个以上可能被深挖的点）

### 4.3 失败/反思类
面试官想看真实与成长。准备 1-2 个真实失败案例：背景 → 你的责任（不甩锅）→ 学到什么 → 后来如何改进。

### 4.4 动机与匹配类
- 为什么做 AI PM？为什么选这家公司/岗位？
- 职业规划？（与[职业规划](05_职业规划.md)一致即可）

## 五、反问环节（同样是考核）

好问题既收集信息又展示水平：
- 团队当前 AI 产品最核心的挑战/指标是什么？
- 产品和算法团队如何协作、效果问题如何决策？
- 这个岗位前 3 个月希望我达成什么？
- 团队如何评估 AI 产品成功与否？
- 数据/模型/工程上目前最大的约束是什么？

避免只问薪资假期（可留到 HR 面/offer 阶段）。

## 六、表达技巧与注意事项

1. **用数据说话**："提升很多"→"Top-3 召回率从 52% 提到 83%"
2. **讲人话**：面对非技术面试官，技术概念要能翻译成业务价值
3. **结构清晰**：用"第一/第二/第三"，避免散乱
4. **真诚务实**：不懂就说"这块我了解不深，但我的理解是……"，不要硬编
5. **掌控节奏**：被问宽泛问题时，先给框架再展开，并可确认"需要我深入哪部分"
6. **展示思考过程**：AI 领域很多问题无标准答案，展示你的分析框架比背答案更重要

## 七、面试准备流程

```
研究 JD 与公司 → 梳理匹配点 → 准备 3-4 个 STAR 故事（覆盖成功/失败/协作/数据）
  → 准备 AI 专业问题清单 → mock interview → 面试后复盘记录
  → 多场迭代优化表达
```

每次面试后立刻记录：被问了什么、哪里答得不好、如何改进。

## 八、常见误区

| 误区 | 纠正 |
|------|------|
| 堆砌 AI 术语、概念 | 讲清楚业务问题与你的决策 |
| 只讲做了什么不讲结果 | 量化结果 |
| 回答没有结构 | 结论先行 + 分点 |
| 不懂装懂被一问就穿 | 诚实 + 展示学习能力 |
| 不准备失败案例 | 真诚的反思很加分 |
| 反问环节说"没问题" | 准备高质量问题 |
| 一份答案投所有公司 | 针对 JD 调整匹配点 |

## 九、自测题

1. 用 30 秒做一个 AI PM 自我介绍。
2. 用 STAR 讲你最成功的 AI 项目，控制在 3 分钟并包含 3 个量化结果。
3. "RAG 效果不好怎么优化"，给出你的排查与优化框架。
4. 讲一个真实失败案例，重点是你学到了什么。
5. 准备 3 个向业务面试官提出的高质量问题。
