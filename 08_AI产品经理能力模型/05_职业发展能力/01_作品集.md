# 作品集

> 所属维度：职业发展能力 ｜ 参考分：66

## 一、能力定义

作品集（Portfolio）是系统展示你**产品思维、项目成果与专业能力**的材料集合。简历是"目录"，作品集是"证据"——它证明你简历上写的都是真的、且有深度。

对 AI PM，作品集更是展示技术理解力与差异化价值的关键载体。

## 二、为什么 AI PM 尤其需要作品集

- AI PM 是新岗位，面试官难以仅凭头衔判断你的真实水平
- "做过 AI 产品"水分很大，作品集能区分"套壳聊天框"和"真正设计过 RAG/Agent/评估体系"
- 作品集是持续积累的个人品牌资产

## 三、作品集应包含什么

1. **个人简介**：定位一句话（如"专注企业级 AI Agent 的产品经理"）+ 核心标签
2. **精选项目案例（2-4 个）**：质量优先于数量
3. **方法论沉淀**：文章/框架（如你设计的 RAG 评估体系），体现思考深度
4. **补充材料**：原型、PRD 节选（脱敏）、数据图表、开源/社区贡献
5. **联系方式与简历入口**

## 四、一个优秀项目案例的结构（STAR + AI 特色）

```
背景（Situation）
  - 业务背景、要解决的问题、你的角色与团队规模

任务（Task）
  - 你的目标、关键约束（时间/资源/数据）

行动（Action）—— AI PM 的重头戏
  - 需求与场景如何判断（为什么要用 AI / 用 AI 解决哪一段）
  - 方案选型：为什么用 RAG 而不是微调？为什么选模型 A？
  - 你设计的：Prompt / Agent 架构 / 工作流 / 知识库策略 / 人机协同边界
  - 评估体系：用什么数据集、什么指标、如何定上线门槛
  - 如何平衡效果、成本、安全（模型路由、人工确认等）
  - 跨团队如何协作推进

结果（Result）—— 必须量化
  - 效果指标：Top-3 召回率 52%→83%、归因准确率 55%→82%
  - 业务指标：MTTR 降 50%、采纳率 40%、留存/收入变化
  - 成本指标：token 成本下降 43%
  - 过程结果：从 0 到 1 搭建了评估体系/知识库

反思（Reflection）—— 拉开差距的部分
  - 如果重来会怎么改？踩过什么坑？沉淀了什么方法论？
```

## 五、AI PM 作品集的加分项

- LLM 效果对比评测（你如何选型、数据如何）
- RAG 召回率优化的完整过程与数据
- Agent 架构图、工作流图（证明你懂系统而非只提需求）
- Prompt 版本迭代记录与回归评测（体现工程化思维）
- 成本-效果权衡的真实决策案例
- 人机协同/安全边界设计（体现成熟度）
- 可演示的 Demo / 原型（哪怕是 Dify 搭的）

## 六、呈现形式

| 形式 | 适合 |
|------|------|
| 在线文档/个人网站（Notion、个人站） | 主流，链接随简历投递 |
| 公众号/知乎/博客文章 | 建立行业影响力 |
| GitHub（若有 Demo/代码参与） | 体现技术理解 |
| PDF（脱敏案例集） | 面试现场/对网络受限岗位 |
| 短视频/演讲 | 表达型、布道型岗位加分 |

## 七、制作原则

1. **脱敏合规**：去除公司机密数据、内部系统名，用相对值/倍数表达
2. **结论与数据前置**：面试官时间有限，开头放最强成果
3. **可视化**：用架构图、流程图、数据图表替代大段文字
4. **讲清"你的"贡献**：团队成果中标注你具体负责什么
5. **诚实**：经得起深挖，不夸大；不懂的不要写
6. **持续更新**：每完成一个重要项目就补充

## 八、常见误区

| 误区 | 纠正 |
|------|------|
| 只罗列岗位职责 | 要讲决策、过程、量化结果 |
| 没有数据 | AI PM 成果尽量全部量化 |
| 只讲做了什么，不讲为什么 | 选型与权衡最能体现水平 |
| 作品很多但都浅 | 2-4 个深挖的精品 |
| 暴露公司机密 | 严格脱敏 |
| 写完不再更新 | 作为长期资产维护 |
| 把团队成果全算自己的 | 明确个人边界 |

## 九、行动清单

- [ ] 选定 2-4 个最能代表你能力的 AI 项目
- [ ] 用 STAR + AI 特色结构重写每个案例
- [ ] 为每个案例补齐量化结果（没有数据就回去找/估算并标注）
- [ ] 画 1-2 张架构图/流程图
- [ ] 补写"反思与方法论"部分
- [ ] 脱敏后发布到在线平台
- [ ] 设置每季度更新一次的提醒

## 十、自测题

1. 你的作品集中有几个能拿出手的 AI 项目？最强的一个 3 分钟能讲清吗？
2. 每个案例是否都有量化的效果/业务/成本结果？
3. 你能讲清一个"为什么选 A 不选 B"的技术权衡吗？
4. 如果面试官深挖你案例里的指标怎么算的，你能答上来吗？
