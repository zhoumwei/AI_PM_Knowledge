# 01 基础产品能力（参考分 78）

> 产品经理的底盘能力。AI 产品经理首先是产品经理，产品基本功的扎实程度决定了 AI 能力能否真正转化为用户价值。

## 能力雷达

```
        需求分析
          80
           |
项目管理 --┼-- 用户调研
  75       |      76
           |
      原型设计 80
        /     \
    PRD 78   竞品分析 75
```

## 学习建议

1. **顺序学习**：需求分析 → 用户调研 → 竞品分析 → PRD → 原型 → 项目管理，正好对应一个产品迭代的完整链路。
2. **结合实战**：以真实项目（如 AIOPS_Troubleshooting_PRD）为载体逐项练习。
3. **AI PM 特别关注**：每篇文档的「AI PM 差异化」小节，是与传统 PM 的关键区别。
