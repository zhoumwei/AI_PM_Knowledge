# 竞品分析

> 所属维度：基础产品能力 ｜ 参考分：75

## 一、能力定义

竞品分析是系统性地**识别、评估、对比**竞争产品（含替代品），从而明确自身定位、发现差异化机会、预判市场趋势的能力。

AI 时代的竞品分析不仅要对比功能，还要**看懂竞品背后的 AI 技术方案及其效果边界**。

## 二、竞品的三种类型

| 类型 | 定义 | 示例（以 AIOPS 排障为例） |
|------|------|---------------------------|
| 直接竞品 | 解决同一问题、目标用户相同 | 阿里云 AIOps Agent、PagerDuty Copilot |
| 间接竞品 | 解决同一问题、形态不同 | 传统监控告警平台 + 人工值班 |
| 替代品 | 用户用非产品方式解决 | 内部 SOP 文档、专家经验、Excel |

> 最危险的往往不是直接竞品，而是"用户已经习惯的土办法"。

## 三、核心分析框架

### 3.1 信息收集维度

| 维度 | 具体内容 |
|------|----------|
| 公司与背景 | 团队、融资、发展阶段、战略意图 |
| 目标用户 | 服务谁、主打什么场景 |
| 产品定位 | 一句话价值主张 |
| 功能清单 | 核心功能、特色功能、功能完整度 |
| AI 能力 | 用了什么模型、RAG/Agent 方案、效果表现 |
| 交互体验 | 关键流程、信息架构、亮点与槽点 |
| 商业模式 | 定价、计费单位、免费策略、客单价 |
| 用户口碑 | 评价、投诉点、NPS、社区活跃度 |
| 优劣势 | SWOT |

### 3.2 功能对比矩阵

| 功能 | 我方 | 竞品 A | 竞品 B | 竞品 C |
|------|------|--------|--------|--------|
| 告警归因 | 有（LLM） | 有（规则） | 无 | 有 |
| 多轮深挖 | 有 | 无 | 有 | 无 |
| 私域知识库 | 有 | 部分 | 有 | 无 |
| 私有化部署 | 支持 | 不支持 | 支持 | 支持 |

标注时区分：**有/无、强/弱、实现方式差异**，而非简单打勾。

### 3.3 定位图（Perceptual Map）

选两个关键维度作 XY 轴，把竞品和自己放上去找空白。
例：横轴"自动化程度（建议→自动执行）"，纵轴"部署模式（SaaS→私有化）"，可发现"私有化 + 高自动化"象限空白。

### 3.4 SWOT

- S/W 内部：我们的优势/劣势
- O/T 外部：市场机会/威胁
- 关键是组合出策略：SO（优势抓机会）、WT（劣势避威胁）

## 四、实操流程

```
确定分析目的 → 圈定竞品（3-5 个）→ 制定对比维度 → 深度体验+资料收集
   → 绘制对比矩阵/定位图 → 提炼差异化 → 输出结论与行动建议
```

### 深度体验 AI 竞品的方法
1. **完整走通核心链路**（注册→首次使用→核心任务→付费墙）
2. **记录 AI 表现好的具体场景**（什么问题答得准、体验流畅）
3. **记录 AI 翻车场景**（幻觉、答非所问、延迟、兜底缺失）——这是机会点
4. **试探边界**：问专业问题、模糊问题、诱导性问题，观察鲁棒性
5. **抓计费细节**：免费额度、超量价格、企业版差异
6. **看更新节奏**：订阅 release notes / changelog

## 五、AI PM 差异化：看懂"技术含量"

| 观察点 | 能推断什么 |
|--------|-----------|
| 是否能基于用户私有数据回答 | 是否有 RAG / 知识库 |
| 回答是否带来源引用 | RAG 可解释性设计 |
| 能否调用外部工具/执行操作 | 是否有 Agent / Function Calling |
| 多步任务能否连贯完成 | 是否有多 Agent / 工作流编排 |
| 响应是一次性还是流式 | 前端与模型工程能力 |
| 专业领域准确率 | 是否做过领域微调 |
| 出错时如何兜底 | 人机协同与安全设计 |
| 响应速度与价格 | 模型选型与成本策略 |

## 六、常见误区

| 误区 | 纠正 |
|------|------|
| 竞品有什么我们就抄什么 | 分析其背后的用户问题，而非功能本身 |
| 只列功能清单，无结论 | 必须输出 So What（差异化/行动） |
| 忽视替代品和"不消费" | 分析用户现状土办法 |
| 只体验一次 | AI 产品有概率性，应多次测试同类问题 |
| 静态分析，不跟踪变化 | 建立竞品跟踪表，定期更新 |
| 只看官方宣传 | 结合真实用户评价与实际体验 |

## 七、输出物模板

```markdown
# [竞品] 分析报告
1. 一句话结论：竞品在 __ 强、__ 弱，我们的机会是 __
2. 基本信息与定位
3. 功能对比矩阵
4. AI 能力拆解（模型/RAG/Agent/效果）
5. 体验亮点与翻车记录（带截图）
6. 商业模式与定价
7. SWOT
8. 对我方的 3 条行动建议
```

## 八、自测题

1. 你能不看资料说出 3 个竞品各自的核心短板吗？
2. 你最近一次记录竞品 AI"翻车"是什么场景？你能利用它做什么？
3. 在定位图上，你所在产品处于什么位置？空白机会在哪？
4. 你的竞品跟踪表多久更新一次？
