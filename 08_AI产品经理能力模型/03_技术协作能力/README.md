# 03 技术协作能力（参考分 64）

> AI PM 不必亲手写代码，但必须**看懂技术方案、与研发高效对齐、提前识别技术风险**。这是许多产品/运营背景转 AI PM 的最明显短板。

## 学习心法

1. **目标不是成为工程师，而是"能对话、能判断、能提问"**：听得懂研发说什么，问得出关键问题。
2. **以一次完整请求为主线**：从前端点击 → 网络 → 后端 → 数据库 → 模型 → 返回，把零散知识串起来。
3. **多动手**：用 Postman 调一次 API、写几条 SQL、本地跑一个向量库 Demo，胜过读十篇文章。
