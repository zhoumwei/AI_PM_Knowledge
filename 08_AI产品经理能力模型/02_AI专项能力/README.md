# 02 AI 专项能力（参考分 72）

> AI 产品经理区别于传统 PM 的**核心壁垒**。这一维度决定了你设计的 AI 产品是"真正用上了模型能力"，还是"套壳一个聊天框"。

## 能力清单

| 序号 | 能力 | 核心问题 | 文档 |
|------|------|----------|------|
| 01 | Prompt 设计 | 如何让大模型稳定输出高质量结果 | [01_Prompt设计.md](01_Prompt设计.md) |
| 02 | 大模型理解 | 模型能力边界、成本与选型 | [02_大模型理解.md](02_大模型理解.md) |
| 03 | RAG 知识库 | 如何让模型基于私有知识回答 | [03_RAG知识库.md](03_RAG知识库.md) |
| 04 | Agent 产品设计 | 如何设计能感知-推理-行动的智能体 | [04_Agent产品设计.md](04_Agent产品设计.md) |
| 05 | AI 工作流设计 | 如何编排多个 AI 节点为业务流程 | [05_AI工作流设计.md](05_AI工作流设计.md) |
| 06 | 模型评估 | 如何量化衡量 AI 好不好 | [06_模型评估.md](06_模型评估.md) |

## 能力关系

```
大模型理解（地基：知道模型能做什么）
    │
    ├── Prompt 设计（单模型调用）
    │
    ├── RAG 知识库（模型 + 私有数据）
    │
    ├── Agent 产品设计（模型 + 工具 + 自主决策）
    │
    └── AI 工作流设计（多个能力编排）
                │
                ▼
          模型评估（贯穿始终的质量保障）
```

## 学习建议

1. 先读 [02_大模型理解](02_大模型理解.md) 建立对 LLM 的正确预期。
2. Prompt 和 RAG 是当前 AI PM 最高频实战技能，优先掌握。
3. 结合 [07_AI Agent产品设计](../../07_AI%20Agent产品设计/) 模块深入原理。
4. 所有能力最终都要落到 [06_模型评估](06_模型评估.md)——不能度量就不能改进。
