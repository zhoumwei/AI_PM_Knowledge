# AI产品经理知识库

---

## 知识库概览

本知识库旨在帮助产品经理快速构建AI领域的知识体系，从技术基础到产品实践，从方法论到行业案例，形成完整的能力闭环。

### 目标读者

- **初级AI产品经理**：快速入门AI产品领域
- **资深产品经理**：系统提升AI产品能力
- **产品总监/负责人**：构建AI产品战略视野

## 各模块说明

### 01_AI技术基础

理解AI产品的底层技术原理，包括：
- 机器学习基础概念（监督学习、无监督学习、强化学习）
- 深度学习核心技术（神经网络、CNN、RNN、Transformer）
- 大语言模型原理（LLM、微调、提示工程）
- 计算机视觉基础（图像分类、目标检测、图像生成）

### 02_AI产品方法论 ⭐ 核心模块

AI产品经理的核心能力体系，包括：
- AI产品需求分析与场景定义
- 数据策略与数据治理
- AI模型选型与评估
- AI产品指标体系设计
- A/B测试与实验设计

### 03_AI产品设计

AI产品的交互设计与用户体验，包括：
- AI原生交互设计原则
- 人机协同设计模式
- AI产品的可解释性设计
- AI伦理与合规设计

### 04_项目管理与工程实践

AI项目的管理方法与工程实践，包括：
- AI产品研发流程
- MLOps基础与模型部署
- AI项目风险管理
- AI团队协作模式

### 05_行业应用与案例

AI产品在各行业的落地案例，包括：
- 推荐系统产品设计
- 对话AI/聊天机器人设计
- 计算机视觉应用案例
- AI在金融/医疗/教育行业的应用

### 06_工具与资源

AI产品经理常用工具与学习资源，包括：
- 常用AI框架与平台
- 大模型API服务
- 数据标注工具
- 学习资源与社区

### 07_AI Agent产品设计 ⭐ 进阶模块

AI Agent技术原理与产品化路径，包括：
- AI Agent技术原理（感知、决策、规划、工具使用、记忆）
- Agent架构设计（输入层、理解层、规划层、决策层、工具层、执行层、记忆层、反馈层、输出层）
- RAG与知识管理（检索增强生成、向量数据库、知识更新）
- Function Calling技术（工具调用、参数传递、安全性）
- 多Agent协作模式（协作架构、通信机制、任务分配）
- AI Agent产品化路径（落地策略、评估指标、商业化）

### 08_AI产品经理能力模型 ⭐ 成长体系

AI 产品经理五大能力维度、29 项能力的系统化详解（每项独立成文），含自评模板：
- 基础产品能力（78）：需求分析、用户调研、竞品分析、PRD、原型、项目管理
- AI 专项能力（72）：Prompt、大模型、RAG、Agent、工作流、模型评估
- 技术协作能力（64）：API、接口文档、数据结构、前后端、向量库、日志监控
- 商业化能力（58）：定价、增长、数据分析、成本、留存转化、SaaS 商业模式
- 职业发展能力（68）：作品集、面试表达、项目复盘、简历优化、职业规划

## 语音播放

项目内置了一个基于 Edge-TTS 的本地语音播放服务，可以把 Markdown 文档按段落朗读，并支持语音选择、语速调节、段落高亮、断点续播和本地音频缓存。

### 启动方式

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

启动后访问：

```text
http://localhost:8899
```

### 播放操作

- 左侧选择文档，右侧会展示可朗读段落。
- 点击文档列表中的播放按钮可直接朗读整篇文档。
- 点击正文段落可从指定段落开始播放。
- 空格键暂停/继续，左右方向键切换上一段/下一段。
- 语音和语速会保存在浏览器本地，下次打开自动沿用。
- 合成后的音频会缓存在 `.tts_cache/`，后续播放同一段会更快。
